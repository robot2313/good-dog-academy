# Milestone 12 — Six-Screen Reference UI

## Goal

Match the approved six-screen direction while preserving all lesson, progress, storage, safety, and self-directed-learning behaviour.

## Implemented screens

1. **Home** — greeting and dog photo, Today’s Plan, Recommended For You, Jump Back In, and compact category shortcuts.
2. **Categories** — ten clean category rows with a coloured line icon, lesson count, and chevron.
3. **Lessons in Category** — category identity, realistic hero photo, difficulty chips, and numbered lesson rows.
4. **Lesson Detail** — full-width realistic hero photo, back and bookmark controls, lesson metadata, learning outcomes, and a fixed green Start Lesson action.
5. **Journey** — four recommended stages with progress counts, completed/current/locked states, and expandable lesson rows.
6. **Training by Life Stage** — Puppy, Adult Dog, Senior Dog, and Rescue Dog photo cards.

## Navigation

The bottom navigation now follows the reference exactly: **Home, Journey, Categories, Dogs, Progress**. The Dogs tab opens life-stage training. The dog profile remains available from the menu button on Home.

## Visual system

- Warm cream app canvas
- Deep navy headings and active navigation
- White rounded cards with thin warm-grey borders
- Green progress, checks, and primary actions
- Restrained gold accents
- Realistic dog photography only

## Non-negotiable image rule

Cartoon, illustrated, or CGI lesson imagery is prohibited. All lesson and discovery screens must use approved realistic photographs.

## Device review checklist

- Confirm the five tab labels fit cleanly on the target iPhone.
- Confirm long dog, owner, category, and lesson names wrap without clipping.
- Confirm each category opens its six lessons.
- Confirm the Dogs tab opens the four life-stage cards.
- Confirm every lesson detail uses the correct realistic photo.
- Confirm Journey and self-directed lesson access remain separate and functional.
- Confirm Profile is reachable from the Home menu and can return to Home.
